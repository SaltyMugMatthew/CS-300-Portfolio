# CS 300: Data Structures and Algorithms

## Course Portfolio Reflection

### What was the problem you were solving in the projects for this course?

Throughout CS 300, the primary objective was to develop a program capable of efficiently organizing, storing, and retrieving course information for a Computer Science academic advising system. The program needed to read course information from a file, organize the courses in alphanumeric order, and allow users to search for specific courses and view their prerequisites.

Project One focused on evaluating different data structures, including vectors, hash tables, and binary search trees, to determine which would best support the program's requirements. This involved analyzing the run-time and memory efficiency of each structure and considering how those characteristics would affect the program's performance. Project Two built upon this analysis by implementing a functional C++ program that could process course information and provide users with an organized, accessible way to review the curriculum.

### How did you approach the problem? Consider why data structures are important to understand.

My approach began with breaking down the program's requirements and identifying the operations necessary to achieve its objectives. Rather than immediately developing the code, I considered how different data structures would influence the efficiency of storing, searching, and sorting course information.

Understanding data structures is essential because the way information is organized directly affects how efficiently a program operates. For example, vectors provide a straightforward method of storing information but may require additional sorting and searching operations. Hash tables offer efficient average-case lookup capabilities, while binary search trees can support ordered traversal and efficient searching when appropriately balanced.

Evaluating these differences helped me recognize that choosing a data structure involves more than simply selecting an option that works. It requires considering the specific needs of the application, the operations performed most frequently, and the trade-offs between processing time, memory usage, and implementation complexity.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of the more challenging aspects of these projects was understanding how the theoretical performance of different data structures translated into practical programming decisions. Although the structures could accomplish similar objectives, their differences in organization, efficiency, and implementation required careful consideration.

Breaking the larger problem into smaller components helped me work through these challenges. I approached the program by examining individual responsibilities, such as reading data from a file, validating course information, organizing records, and retrieving specific courses.

I also found that reviewing pseudocode and considering the expected behavior of each function helped clarify the relationship between the program's design and its implementation. This reinforced the importance of testing individual components, examining unexpected results, and approaching programming challenges systematically rather than attempting to resolve everything at once.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects expanded my understanding of software development by demonstrating the importance of evaluating design decisions before beginning implementation. Previously, it was easy to focus primarily on whether a program could successfully complete its intended task. Through this course, I developed a greater appreciation for how the underlying design affects performance, scalability, and overall functionality.

Analyzing run-time complexity and memory requirements encouraged me to consider the long-term implications of programming decisions. A solution that performs adequately with a small amount of information may become inefficient as the volume of data increases.

I also gained a better understanding of how planning, pseudocode, and algorithm analysis contribute to successful software development. These practices allow developers to identify potential inefficiencies and design limitations before they become more difficult to address during implementation.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work in CS 300 reinforced the importance of writing code that is not only functional but also understandable and adaptable. By separating the program into smaller functions with clearly defined responsibilities, I learned how modular design can simplify troubleshooting, testing, and future modifications.

I also developed a stronger appreciation for meaningful variable names, consistent formatting, clear documentation, and appropriate error handling. These practices improve readability and make it easier for another developer to understand the program's purpose and functionality.

Perhaps most importantly, this course helped me recognize that maintainability begins during the design process. Selecting an appropriate data structure, minimizing unnecessary complexity, and organizing code logically can make a program easier to expand as requirements change.

Moving forward, I intend to apply these principles by evaluating efficiency alongside functionality, planning program structure before implementation, and developing solutions that balance performance with readability and maintainability.
